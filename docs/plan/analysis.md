## Phase 6: Errors, logging, validation
- [x] Step 14: `ThreadingHTTPServer` handler `timeout`, check token before reading body, negative `Content-Length` rejected (fixes I-ANALYSIS-5, I-ANALYSIS-15; touches F9)
  Done 2026-11-23: `Handler.timeout = 10` (per socket read/write, not scoring time). Checked by hand on a real socket with the timeout set to 1 s: a client that never finishes its headers is dropped after 1.0 s. The token and path were already checked before the body; this is now pinned by a reader that records `read()` calls. `Content-Length` must be a plain ASCII non-negative integer, otherwise 400 `invalid Content-Length` before any read (negative, `abc`, `1e3`, `0x10`, non-ASCII digits; non-numeric used to give 422). The 64 KiB cap (`MAX_BODY`) is unchanged, as pinned in Step 1. Not done: the audit's optional cap on concurrent connections, which this step does not list. 3 tests + 6 parametrized cases. 45 passed + 1 xfailed, ruff clean.
- [x] Step 15: `/health` reuses one connection (pool) and closes it; rate-limited (fixes I-ANALYSIS-6; touches F9)
  Done 2026-11-23: new `service.HealthCheck` (module-level `HEALTH`): one DB connection behind a lock, reused across requests. The answer is cached for 5 s, so the DB sees at most one `SELECT 1` per 5 s however often `/health` is called; that is the rate limit. A failed ping closes the connection and retries once with a fresh one, so a connection MySQL dropped (`wait_timeout`) gives no false 503. A DB that cannot be opened is now 503 `{"ok": false}` with a log warning; it used to raise out of the handler and drop the connection (pinned in Step 1, test flipped here). 4 unit tests with a fake DB and clock (50 calls = 1 query; recheck after 5 s on the same connection; reconnect once; DB down = false and rate-limited; 20 concurrent calls = 1 check) and an autouse fixture that gives each service test a fresh `HEALTH`. Not in this step: `/score` still opens a `Db()` per request and never closes it. 49 passed + 1 xfailed, ruff clean.
- [x] Step 16: Distinguish `KeyError` for missing `session_id` (422) from internal errors (500) (fixes I-ANALYSIS-14; touches F9)
  Done 2026-11-23: `load_session` raises the new `features.SessionNotFound` (a `LookupError`, not a `KeyError`). `do_POST` parses first, then scores. A body that is not an object or has no `session_id` is 422 `session_id is required` (was 404); a non-integer id is still 422. During scoring only `SessionNotFound` is 404 and everything else is 500, `ValueError`/`TypeError` included (before, a pandas `ValueError` such as the I-ANALYSIS-3 crash answered 422, which `AnalysisClient` treats as permanent and never retries; 500 is retried). No server change needed. The Step 1 pin is flipped; 2 new parametrized tests (3 missing-id bodies, 3 internal error types → 500). 55 passed + 1 xfailed, ruff clean.
- [x] Step 17: 500 responses return a generic message plus an error id; details only in the log (fixes I-ANALYSIS-16; touches F9)
  Done 2026-11-23: a 500 body is now `{"error": "internal error", "error_id": "<12 hex>"}`. The exception and traceback go to `log.exception("scoring session N failed (error_id=…)")`. 404/422 texts are unchanged (they hold only the session id or a parse error). `AnalysisClient` does not read the body of a 5xx, so no server change. Possible follow-up (server, not planned): show the `error_id` in the failed report reason. New test with a pymysql-style "Access denied for user …@host" error: not in the body, found in the log record under the id; ids differ per call. 56 passed + 1 xfailed, ruff clean.
- [x] Step 18: `load_session` selects only needed student columns, never the real `name` (fixes I-ANALYSIS-20; touches F48) [update ETHICS.md note]
  Done 2026-11-23: the roster SELECT is now `id AS student_id, login, exempt, exempt_reason`. `name` and also `pseudonym` (the audit kept it, but analysis never uses it; pseudonyms are the server export's, DECISIONS #30) are dropped. New `test_roster_load_has_no_name_number_or_pseudonym` (exact columns; no name/number/pseudonym value in any cell). 57 passed + 1 xfailed, ruff clean.
